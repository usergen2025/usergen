# Managing Workspaces

## What are Workspaces?

Workspaces are collaborative spaces where you can work with team members, share credits, and manage projects together.

## Creating a Workspace

### Step 1: Create a New Workspace
1. Go to "Workspaces" in the navigation menu
2. Click "Create Workspace"
3. Enter workspace details:
   - Name (e.g., "Marketing Team")
   - Description (optional)
4. Click "Create"

### Step 2: Customize Your Workspace
- Add workspace avatar/logo
- Set workspace settings
- Configure permissions (if you're the owner)

## Inviting Team Members

### Send Invitations
1. Open your workspace
2. Go to "Members" tab
3. Click "Invite Member"
4. Enter member's email address
5. Choose their role:
   - **Admin** - Can manage members and settings
   - **Member** - Can create and use content
   - **Viewer** - Can view but not create content
6. Click "Send Invitation"

### Accepting Invitations
1. Check your email
2. Click the invitation link
3. You'll be added to the workspace automatically

## Workspace Roles

### Owner
- Full control of the workspace
- Can delete workspace
- Manage all settings
- Manage all members

### Admin
- Can manage members
- Can manage settings
- Cannot delete workspace
- Can create and use content

### Member
- Can create and use content
- Can view workspace resources
- Cannot manage members
- Cannot change settings

### Viewer
- View-only access
- Cannot create content
- Cannot make changes

## Managing Members

### As Owner or Admin:
- View all members
- Change member roles
- Remove members
- View member activity

### To Change a Role:
1. Go to Workspace → Members
2. Find the member
3. Click on their role
4. Select new role
5. Save changes

## Workspace Credits

### Shared Credits
- Workspaces have their own credit balance
- Credits are shared among all members
- Owner can purchase credits for the workspace

### Using Credits
- When creating content in workspace context, workspace credits are used
- Check balance in workspace dashboard
- Owner/admins can view credit usage

## Switching Between Individual and Workspace

### Switching Context:
1. Click your profile/workspace switcher
2. Select "My Account" for individual mode
3. Select workspace name for workspace mode

### Individual Mode
- Uses your personal credits
- Content is private
- No team collaboration

### Workspace Mode
- Uses workspace credits
- Content is shared with team
- Collaborate with members

## Best Practices

1. **Organize** - Create workspaces for different projects or teams
2. **Permissions** - Assign appropriate roles to members
3. **Communication** - Use workspace features to collaborate
4. **Credits** - Monitor workspace credit usage
5. **Members** - Regularly review and update member list

## Leaving a Workspace

If you need to leave a workspace:
1. Go to workspace settings
2. Click "Leave Workspace"
3. Confirm your decision

**Note:** You cannot leave if you are the owner. Transfer ownership first if needed.
